# Клиентские данные

CRM, история отношений и записи интервью не предоставлены. В папке пока нет клиентских выводов: публичные сведения о компаниях не считаются словами клиентов.

После каждого разговора сюда нужно сохранить обезличенную карточку: компания-код, роль собеседника, недавняя ситуация, последствие, текущий обходной путь, дословная формулировка проблемы, возражение, встречный шаг и дата следующего действия.
