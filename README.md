# Исследование тёплых каналов продаж для Стенгазеты 2.0

Общее рабочее пространство Pike Media Lab для первой продажи продукта «Стенгазета 2.0».

Здесь собраны не только выводы, но и вся логика принятия решений: кому продавать, по какому событию находить компанию, с каким сообщением входить, как за две встречи дойти до платного пилота и по каким фактам понимать, что гипотеза работает.

## Главный фокус

- компании на 30–300 сотрудников;
- небольшие сети на 3–20 филиалов или точек;
- новый офис на 40+ человек;
- свежий триггер: открытие, переезд, быстрый найм, новый филиал, объединение команд;
- решение принимает собственник, CEO, операционный директор, HRD или административный директор;
- пилот можно начать на 1–3 существующих экранах без длинного корпоративного тендера.

## Первая рабочая воронка

**20 подходящих компаний → 12 личных входов → 8 разговоров → 4 персональных показа → 2 обсуждения пилота → 1 оплата или письменное обязательство.**

Срок первой волны — 10 рабочих дней.

## Ценовая гипотеза

- «Новый офис» — 69 000 ₽ за 4 недели, один офис, до трёх экранов;
- «Небольшая сеть» — 99 000 ₽ за 4 недели, три филиала, до шести экранов;
- оборудование и программное обеспечение считаются отдельно.

Цена пока является проверяемой гипотезой, а не подтверждённым рынком прайсом.

## Как открыть рабочую страницу

```bash
pnpm install
pnpm dev
```

После запуска открыть `http://localhost:3000`.

## Правила работы команды

1. Не считать «интересно» и «пришлите презентацию» доказательством спроса.
2. Для каждой компании фиксировать событие, ЛПР, маршрут входа и следующий шаг с датой.
3. Не менять продукт под каждый разговор: сравнивать одинаковый пилот и разные формулировки.
4. Не публиковать персональные данные и закрытую CRM-информацию в репозитории.
5. Все новые факты добавлять со ссылкой и датой проверки.
